        Contribuer à la carte

        Tu peux dessiner des zones et des îles, et placer des PNJ, puis nous envoyer tes ajouts.

        1 Ouvrir le mode édition

        Le mode édition ajoute les outils dans le menu de gauche (section Édition).

        Tu es déjà en mode édition : les outils sont dans le menu de gauche (section Édition).

        Ouvrir le mode édition

        2 Dessiner une zone ou une île

        • Clique + Nouvelle zone, ou + Nouvelle île pour le contour d'une île entière.
        • Clique sur la carte pour poser chaque coin. Retour arrière enlève le dernier point.
        • Pour terminer : double-clic, Entrée ou clic sur le premier point. Échap abandonne.
        • Remplis la fiche à droite : nom, type, couleur, description.
        • Pour corriger une zone, clique-la puis glisse ses points.

        3 Ajouter un PNJ

        • Clique + Nouveau PNJ, puis clique sur la carte à sa place.
        • Remplis sa fiche : nom, rôle, description. Coche Se déplace s'il se promène.
        • Pour le déplacer : glisse son point, utilise Déplacer… ou tape X / Y.
        • Les coordonnées X, Y sont affichées en bas de l'écran sous la souris.

        4 Télécharger tes ajouts

        Ton travail est gardé automatiquement dans ce navigateur, mais personne d'autre ne le voit. Quand tu as fini, clique dans le menu de gauche :

        • Exporter zones-data.js (zones et îles)
        • Exporter pnj-data.js (PNJ)

        Les deux fichiers arrivent dans ton dossier Téléchargements.

        5 Nous les envoyer

        Envoie les deux fichiers .js en pièces jointes à ericwebprogrammer@gmail.com.

        Écrire le courriel

        Le courriel ne joint pas les fichiers tout seul : ajoute-les toi-même avant d'envoyer.
